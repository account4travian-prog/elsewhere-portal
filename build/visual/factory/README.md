# Avatar Factory — Termi overhaul, build/factory

Reusable scripted Blender → glTF avatar factory (BUILD-PLAN §3, the project owner's
D5 requirement). One shared rig, per-persona data kits, no bespoke model
files. Hark is excluded by design (WFH only, DECISIONS 17).

## Layout
- `kits/kit.schema.json` — kit schema. `kits/{atlas,builder-1,verifier-1,alpha-lead}.json` — persona kits (palette, face values, ear/snout/tail style, props at 125%, clip source).
- `scripts/build_avatar.py` — the factory. Builds a low-poly stylised figure from primitives + generated tube meshes, binds every mesh to the shared armature, generates a procedural face texture from kit colours, builds `prop.<name>` meshes, creates the 8 named clips, renders front/iso + sit/type pose checks (Workbench engine — EEVEE stalls headless on GPU-less hosts), exports the GLB.
- `scripts/validate_glb.py` — dependency-free GLB validator (parses the JSON chunk): sizes, meshes, triangles, bone names vs contract, clip names, props, extras.
- `scripts/load_test.mjs` — three.js GLTFLoader load test (uses the locally vendored three 0.186.1 in `agent-office/spike/agent-office/node_modules`; in Node the embedded PNG texture cannot decode — geometry/skins/animations parse; browsers decode the texture normally).
- `outputs/*.glb`, `outputs/validation.json`, `outputs/three-load-test.txt`; `renders/*.png`.

## Rig contract (SOFTWARE-DESIGN §2.2, exact)
Bones: `hips, spine, chest, head, arm.L/R, forearm.L/R, hand.L/R, leg.L/R, shin.L/R` — plus only namespaced `extra.tail`, `extra.ear.L/R`. Clips, no others: `idle, sit, type, stand, walk, knock, wait, gather`.

## Clip sources (per clip, recorded in kit + GLB extras)
UAL1 (CC0) was downloaded to `build/assets` during the build (see
`UAL-NOTES.md` in this folder), so the factory retargets it onto the spec
rig by world-space rotation deltas (`--ual <AnimationLibrary GLB>`):
`idle`←Idle_Loop, `walk`←Walk_Loop, `sit`←Sitting_Enter,
`stand`←Sitting_Exit, `wait`←Idle_Loop at stride 2, `gather`←Idle_Talking_Loop.
UAL has no typing or knock clip (RESEARCH §4.1), so `type` (seated pose
captured from the baked sit + procedural forearms) and `knock` are
procedural — every clip's source is in each kit's `clip_sources` map and
in the GLB armature extras. Run without `--ual` and everything falls back
to procedural, marked the same way.

## Rebuild
```
BL=~/workspace/tools/blender/blender-5.2.2-linux-x64/blender
$BL -b --python scripts/build_avatar.py -- --kit kits/atlas.json \
    --output outputs/atlas.glb --renders renders \
    --ual "../assets/extracted/ual1-standard/Animation Library[Standard]/Godot/AnimationLibrary_Godot_Standard.glb"
python3 scripts/validate_glb.py outputs/atlas.glb
node scripts/load_test.mjs outputs/atlas.glb
```

## Licences
Model geometry: no external assets — every mesh is generated in-script
from Blender primitives / swept tubes, the face texture is generated
from kit colours, and the 2D masters are project-owned design
references only. Animation: Quaternius Universal Animation Library 1
(CC0 1.0, licence file in the source zip in `build/assets`) for the six
retargeted clips listed above; `type`/`knock` are original procedural
clips generated by this factory. Output is project-owned / CC0-derived.

## Portal extensions (M4.05 — this copy only; the Office source is unchanged)

This tree is the Elsewhere Portal's registered copy of the factory
(~/workspace/elsewhere-portal/EXTRACTIONS.md, Entry 2). Portal-side
additions, all under the web profile (plan §5.2 / SE-4.2):

- `web-profile.json` — the LOD budgets (lod0 ≤ 120 KB / ≤ 2,500 tris,
  lod1 ≤ 40 KB / ≤ 800 tris, lod2 standee ≤ 8 KB) and how each is met.
- `scripts/validate_glb.py` gained the size gate: `--profile <p> --gate`
  exits 1 over budget, 2 for a budget-less/unknown profile; no-flag
  behaviour is the Office original, byte-for-byte in content.
- `scripts/web_profile.py` — Blender post-processor: re-imports a factory
  GLB, decimates to the profile's triangle budget, scales textures to
  the profile cap, subsets clips for lod1, optionally flattens image
  textures to flat material colours (lod1's profile does).
- `scripts/transcode_images.py` — PNG→JPEG for the painted cards (the
  Blender exporter re-encodes packed images as PNG regardless of the
  datablock format; observed, recorded in the factory STATUS).
- `tools/gltfpack/` — meshopt compression (meshoptimizer 0.24, MIT,
  github.com/zeux/meshoptimizer release binary; SHA-256 in STATUS).
  gltfpack drops node extras even with -ke, so
  `scripts/patch_extras.py` restores the Armature extras (the clip-source
  record) from the source GLB afterwards — that step is test-pinned.
- `scripts/load_test_web.mjs` — load test for meshopt output (the lifted
  `load_test.mjs` has no MeshoptDecoder and refuses such files; it
  remains the desktop GLBs' test, unmodified).
- `scripts/build_web.sh <persona>` — the whole chain for one kit, ending
  in the gate; products land in `outputs-web/<persona>--lod0.glb` and
  `--lod1.glb`. Tests: `test/size-gate.test.mjs` (node --test, per-file).
- `assets/ual1/` — the UAL1 library GLB from Portal's own intake
  (assets-src, CC0) for `--ual` build runs on this side.
